> 版本：V1.0

# 1. 全局结构

- **底部导航**：3 个一级 Tab —— **音乐库 / 搜索 / 我的**。
- **常驻 mini 播放条**：固定在**底部导航正上方**，任何 Tab 内都可见、不被内容遮挡；点击展开全屏播放器。
- **覆盖页**（全屏 / 从底部推入，不占 Tab）：全屏播放器、歌词页、播放队列、歌曲详情、分类管理等；返回即回到来源 Tab。
- **沉浸与安全区**：内容避让状态栏/刘海；底部导航与 mini 播放条避让手势区。

```
┌──────────────────────────┐
│        当前 Tab 内容       │
│                          │
│ ┌──────────────────────┐ │  ← 常驻 mini 播放条（点击展开全屏播放器）
│ │ ♪ 歌名 - 歌手  ▶  ☰ │ │
│ └──────────────────────┘ │
│  音乐库    搜索     我的   │  ← 底部导航（3 个）
└──────────────────────────┘
```

# 2. 底部导航

| Tab | 图标语义 | 承载功能 | 默认页 |
| --- | --- | --- | --- |
| **音乐库** | 唱片 / 列表 | 浏览与管理本地歌曲：歌曲 / 歌手 / 专辑 / 标签四个维度、排序筛选、歌曲详情、文件与标签管理入口 | 歌曲列表 |
| **搜索** | 放大镜 | 搜索歌曲、歌手；展示搜索历史 | 搜索页 |
| **我的** | 人像 | 扫描与来源管理、最近分析记录、外部歌词目录、最近播放、设置、关于 | 我的 |

**为什么是 3 个**：底部导航只放"目的地"。内容/社区类 Tab（QQ 音乐的 直播/雷达/社区）我们不适用；**标签不单独做 Tab**——它与歌手、专辑一样是"同一批歌曲的浏览维度"，放在音乐库的维度切换里（参照 QQ「本地歌曲 ▾」切换 歌曲/歌手/专辑/文件夹）。

# 3. 音乐库

**顶部**：搜索入口 + **维度切换**（`歌曲 | 歌手 | 专辑 | 标签`，下拉或子标签）。

## 3.1 歌曲（默认）

- **表头**：`全部播放(N)` + 排序（名称 / 最近播放 / 完播次数）+ 筛选（按名称 / 按歌词）。
- **列表行**：封面、歌名、歌手、专辑、标签（主要分类下的）。**列表不展示时长**。
- **行内操作**：播放、添加到队列、更多（下一首播放 / 查看文件 / 编辑标签 / 删除）。
- **不可用歌曲**：置灰，点击只提示"无可用文件"，不入队。

## 3.2 歌手

- 列表：歌手名 + 歌曲数量。
- 进入：**歌手歌曲列表**（复用歌曲列表，内容限定该歌手）。多歌手歌曲在其涉及的每个歌手下都出现。

## 3.3 专辑

- 列表：封面、专辑名、发行日期、专辑歌手、歌曲数量。
- 进入：**专辑歌曲列表**。

## 3.4 标签

- **分类 & 标签页**（入口）：
  - 分类列表（显示每个分类下的标签数）+「新建分类」
  - 顶部「搜索标签」（标签搜索**仅在此页**可用）
  - 每个分类可设为「主要分类」
- 进入某分类：**该分类下的标签列表**（标签名 + 歌曲数）+「新建标签」。
- 进入某标签：**标签歌曲列表**；支持单条 / 批量从标签中移除歌曲。

## 3.5 歌曲详情（覆盖页）

- 歌曲信息：封面、名称、歌手、专辑。
- 标签区：完整标签，支持增删（分类内选择 / 复用已有 / 新建）。
- 歌词状态：已关联 / 未找到（可删除关联）。
- **管理的文件列表**：路径、大小、格式；支持「移除文件」「物理删除文件」。
- 操作：播放、添加到队列、下一首播放、删除歌曲。

---

# 4. 搜索

- **搜索框**：位于页面顶部，进入自动聚焦。
- **搜索历史**：展示最近搜索词，可清空。
- **结果**：**统一列表、不分组**，歌曲与歌手混合展示；点击即播放，行内操作同歌曲列表。
- **标签搜索不在此页**（在 音乐库 → 标签 的分类 & 标签页）。
- 空状态：无历史 / 无结果（见 `../需求文档/05-空状态与异常处理.md`）。

# 5. 我的

| 区块 | 功能 |
| --- | --- |
| **文件扫描** | 音乐来源管理（添加 / 移除目录）、手动重新扫描；二级入口 → **最近分析记录** |
| **最近分析记录**（二级） | 最近一次分析的结果摘要 + 文件清单与状态（未分析 / 分析中 / 已关联〔所属歌曲〕/ 失败〔原因〕）；失败可重试；可触发分析 / 移除记录 / 物理删除文件 |
| **外部歌词目录** | 设置歌词查找目录 |
| **最近播放** | 最近播放列表（持久化，点击播放） |
| **设置** | 播放设置等 |
| **关于** | 版本信息 |

# 6. 播放器

## 6.1 mini 播放条（常驻）

- 内容：封面、歌名、歌手。
- 操作：播放 / 暂停、**播放队列入口**；点击条体 → 展开全屏播放器。

## 6.2 全屏播放器

- **子标签**：`歌曲 | 歌词`（参照 QQ 播放页，把信息/标签与歌词分屏，避免互相抢空间）。
- **歌曲页**：封面、歌名、歌手、**完整标签**、进度条（当前时间 / 总时长，可拖动）、控制（上一首 / 播放暂停 / 下一首）、播放模式切换、队列入口、更多。
- 顶部：收起（下拉返回）。

## 6.3 歌词页

- 跟随播放进度：当前行高亮、自动滚动。
- 多语言：同一时间点多行并列显示。
- 状态：未关联 → 空状态（一期不提供手动选择）；已关联但文件失效 → 提示。

## 6.4 播放队列（覆盖页）

- 当前播放项高亮。
- 操作：跳到某首、移除某项、清空队列（播放队列允许重复）。
- 「下一首播放」插入的强制项排在当前项之后（LIFO）。

# 9. 统一交互规范

## 9.1 单行操作：统一「⋯」唤出，不用左滑

- **点击行体** = 主操作（歌曲：播放；歌手 / 专辑：进入）。
- **行内只保留 1 个快捷动作**：歌曲类保留 `＋ 添加到队列`，其余操作全部收进**行尾 `⋯`**。
- `⋯` → **底部操作面板**（bottom sheet），全应用同一套。
- **不采用左滑**：可发现性差、无障碍差（读屏 / 手部不便用户不可达）、与横向手势冲突，且不同列表可用操作不同，左滑无法表达全集。

## 9.2 操作面板：项目与顺序固定

```
播放 / 下一首播放 / 添加到队列 / 添加到标签 / 查看歌曲详情 / 多选 / 删除歌曲
```

- 各列表按自身能力**裁剪**，但**顺序不变**；不可用项灰置（如受删除保护的项）。
- 非歌曲类列表（如标签、文件记录）展示对应操作，仍遵循"高频在前、删除最后"的顺序。

## 9.3 多选模式

- **进入**：长按任意行；或 `⋯` 面板中的「多选」（兜底入口）。
- **进入后**：行左侧出现勾选圈；**点击行 = 勾选 / 取消**（不再触发播放或进入）；顶部栏变为 `取消 · 已选 N · 全选`；底部出现**批量操作条**。
- **退出**：取消 / 系统返回。
- **全选**：作用于**当前筛选结果**；不可用 / 受保护项不可选。
- 切换筛选或退出时**清空选择**。

## 9.4 支持多选的列表

| 列表 | 多选 | 批量操作 |
| --- | --- | --- |
| 歌曲库 / 歌手 / 专辑 / 标签 的歌曲列表 | ✅ | 加入队列、添加到标签、从当前标签移除、删除 |
| 搜索结果 | ✅ | 加入队列 |
| 播放队列 | ✅ | 移除 |
| 分析文件列表（最近分析记录） | ✅ | 重试分析、移除记录、物理删除 |
| 歌曲详情内的文件列表 | ✅ | 移除文件、物理删除 |
| 某分类下的标签列表 | ✅ | 删除标签（受"有歌不可删"保护的项不可选） |
| 歌手列表 / 专辑列表 | ❌ | 纯导航入口，无批量语义 |

## 9.5 危险操作

- 删除歌曲实体、物理删除文件**统一二次确认**；批量删除需显示**数量**。
- 确认组件与文案风格全应用一致。
