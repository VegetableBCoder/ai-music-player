# 歌曲库管理需求文档 · V1.0

> 版本：V1.0
> 全局概念（歌曲实体、实体身份键、代表文件、扫描分析流水线、删除模型）见 `00-总览.md`。

---

# 1. 模块概述

## 1.1 模块目标

建立一个以「歌曲」为核心的本地音乐管理体系。

用户无需关注音乐文件存储位置，通过播放器自动整理本地音乐，并支持按照歌手、标签、歌曲等多个维度浏览和查找音乐。

## 1.2 设计原则

- 音乐文件仅作为歌曲来源，不作为用户主要管理对象
- 音乐库围绕歌曲实体进行组织
- 支持多维度浏览音乐
- 支持快速搜索，降低多级分类带来的查找成本
- 自动整理与用户主动管理结合

---

# 2. 本地音乐扫描

## 2.1 功能描述

扫描设备中的本地音乐文件，建立音乐文件清单，同时索引来源目录及外部歌词目录下的 `.lrc` 文件（供歌词匹配使用，见 `03-歌词.md`）。

扫描过程仅负责发现本地音乐资源，不负责音乐内容理解和分类。

## 2.2 扫描结果

记录音乐文件基础信息：

- 文件位置
- 文件格式
- 文件大小
- 音乐时长
- 文件中的已有音乐信息（内嵌元数据）

## 2.3 扫描触发

- 首次使用时扫描音乐
- 用户主动重新扫描

## 2.4 扫描来源

用户可管理播放器可访问的音乐文件来源（音乐目录）。

# 3. 歌曲实体与文件

## 3.1 实体身份

实体身份键为 `(规范化歌名, 规范化演唱者集合)`，详见 `00-总览.md` §1.2。

## 3.2 文件挂靠

- 重新扫描不重建实体。
- 文件分析后：`entityKey` 与已有实体一致 → 加入该实体的文件清单；否则新建实体。
- 一个文件同一时间只属于一个实体。
- 已经关联实体的文件不支持重新分析；未关联实体的文件可以分析。
- 不做实体合并；错误关联通过「删除实体 → 文件回到未关联 → 重新分析」纠正。

## 3.3 代表文件

- 播放与实体信息展示以**体积最大**的文件为代表文件。
- 代表文件被删除后，自动回退到次大的文件。
- 展示信息的来源规则见 `00-总览.md` §3。

## 3.4 文件清单查看与管理

- 歌曲支持展开查看其管理的文件列表（路径、大小、格式等）。
- 支持从实体下**移除文件**（解除关联，磁盘保留）与**物理删除文件**。
- 当前版本不提供「筛选存在重复文件」、自动清理重复文件等功能（远期规划）。

## 3.5 不可用歌曲

- 实体无任何可用文件时，该歌曲为**不可用歌曲**（见 `00-总览.md` §1.6）。
- 播放时发现文件缺失 → 提示并清理该记录；代表文件删除则回退次大；实体再无文件 → 提示是否删除（可保留并标记为不可用）。
- 不可用歌曲不得加入播放队列；列表中置灰 / 不可点击。

## 3.6 不主动处理的文件变化

当前版本不处理：

- 文件移动
- 文件重命名
- 文件内容变化

（重新扫描时，移动/重命名的文件会以新记录重新分析，因 `entityKey` 相同通常会自动挂回原实体。）

# 4. 歌曲信息整理

对扫描得到的音乐文件进行整理，生成用户可浏览的歌曲信息，支持完善和修正：

- 歌曲名称
- 歌手列表
- 专辑信息
- 其他歌曲属性

标签信息由 `04-智能标签.md` 生成与维护。

---

# 5. 歌曲库

## 5.1 歌曲展示

支持查看全部歌曲列表。歌曲列表展示：

- 歌曲名称
- 歌手名称
- 专辑信息
- 封面信息
- 标签信息（展示主要分类下的标签，见 `04-智能标签.md`）

## 5.2 歌曲排序

- 名称
- 最近播放
- 完播次数（完整播放次数）

（排序方式适用于歌曲库及各分类歌曲列表。）

## 5.3 筛选

- 按名称筛选
- 按歌词搜索

---

# 6. 歌手

## 6.1 功能描述

根据歌曲所属歌手建立歌曲索引。歌手仅作为音乐分类维度，不提供独立歌手信息模块。

## 6.2 歌手列表

展示：

- 歌手名称
- 歌曲数量

示例：

```
周杰伦   86首歌曲
Aimer   42首歌曲
```

## 6.3 歌手歌曲浏览

用户选择歌手后，直接进入该歌手歌曲列表。多歌手歌曲计入其涉及的每个歌手。

## 6.4 后续规划

支持歌手名称合并和别名管理（如 `Jay Chou` / `周杰伦` / `周董` 归一），当前版本不做。

---

# 7. 专辑

## 7.1 功能描述

支持按照专辑检索歌曲。

## 7.2 封面来源

音乐文件中的内嵌封面。

## 7.3 专辑列表

展示专辑名称、发行日期、专辑歌手、歌曲数量。

示例：

```
爱久见人心   2012-08-10   梁静茹   11首
勇气        2000-08-02             10首
```

## 7.4 专辑归属

- 专辑由「专辑名称 + 专辑歌手」共同确定，同名但不同歌手的专辑视为不同专辑。
- 合辑的专辑歌手由 LLM 归一化判定，记为「多位歌手」。

---

# 8. 标签分类浏览

标签体系、标签来源与生成见 `04-智能标签.md`，本节描述浏览与管理。

## 8.1 标签分类

标签按照类型组织，分类包括：音乐类型、情绪、场景、主题。

## 8.2 分类与标签的创建

- **新建分类**：在「分类 & 标签」页添加分类。
- **新建标签**：在某分类下的标签列表页新建，标签必然归属于某个分类。
- 标签名称**全局唯一**；新建时若名称已存在，引导复用已有标签。

## 8.3 删除保护

- 分类下存在标签时，不允许删除该分类。
- 标签下存在歌曲时，不允许删除该标签。
- 歌曲数量为 0 的标签仍然展示，需要用户手动删除。
- 内置分类 / 标签仅为简化使用，不设保护，允许删除。

## 8.4 标签列表

展示：

- 标签名称
- 包含歌曲数量（即时派生）

## 8.5 标签歌曲浏览

用户选择标签后，进入对应歌曲列表。

## 8.6 标签下的歌曲操作

- 支持从标签下移除单首歌曲
- 支持从标签下批量移除歌曲

## 8.7 主要分类

主要分类由用户在分类页设置（类似收藏），**预置「音乐类型 + 情绪」、可修改**；歌曲列表展示主要分类下的标签（见 `04-智能标签.md` §6）。

---

# 9. 搜索

## 9.1 功能目标

由于音乐分类存在多级结构，需要提供快速搜索入口。

## 9.2 搜索范围

- **歌曲**：根据歌曲名称搜索歌曲列表
- **歌手**：根据歌手名称查找歌曲列表
- **标签**：仅可在「分类 & 标签列表」页搜索标签

搜索结果**不分组**，以统一列表展示；可直接播放或加入播放队列（见 `02-播放器.md`）。

示例：

```
晴天

结果：
晴天      周杰伦
晴天好心情 平野绫
```

三类删除操作（删除歌曲实体 / 移除文件 / 物理删除文件）的规则与确认级别见 `00-总览.md` §5。

# 11. 当前版本范围总结

## 已包含

- 本地音乐扫描、`.lrc` 索引
- 文件清单建立与实体挂靠
- 歌曲信息整理
- 歌曲库管理、歌手 / 专辑 / 标签分类浏览
- 歌曲搜索、歌手搜索、标签搜索（限分类 & 标签页）
- 排序（名称 / 最近播放 / 完播次数）
- 封面展示
- 查看歌曲文件列表、移除文件、物理删除文件
- 播放失败后的文件清理

## 暂不包含

- 收藏模块（远期）
- 歌手详情页面 / 歌手信息介绍 / 歌手智能分析
- 文件实时变化监听、文件自动迁移识别
- 实体合并（含向量检索 + LLM 判定）
- 重复文件筛选与自动清理
- 歌手别名合并
- 拼音 / 首字母搜索
