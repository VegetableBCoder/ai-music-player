# 空状态与异常处理需求文档 · V1.0

> 版本：V1.0
> 全局概念见 `00-总览.md`。本文档集中定义各模块的空状态、失败态与引导。

---

# 1. 首次使用与扫描

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 无权限 / 未指定来源 | 引导选择音乐来源（目录） | 「选择音乐来源」；未选前不启动扫描 |
| 扫描中 | 显示进度（已发现 N 首） | 可后台进行、可「取消」 |
| 扫描到新文件 | 「发现 N 个新文件」+ 摘要（新增 N / 已存在跳过 M / 已删除清理 K） | 「分析并添加」/「放弃」 |
| 扫描无新文件 | 「未发现新文件」 | 「重新扫描」 |
| 扫不到任何歌曲 | 「没有扫描到音乐」 | 提示检查来源 / 权限 +「重新选择来源」/「重新扫描」 |

---

# 2. 分析

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 分析中 | 进度 + 文件清单与状态 | 可后台进行 |
| 部分失败 | 结果摘要（成功 X / 失败 Y） | 「查看详情」进文件列表重试失败项 |
| 全部失败 | 按原因给文案：无网络 / 服务不可用 / 返回异常 | 「全部重试」；入口保留在「文件扫描 → 最近分析记录」 |
| 429 | 显示"重试中" | 不计入失败 |
| LLM 无知识（0 标签） | **不算失败**；歌曲正常入库，标签区显示「暂无标签」 | — |

---

# 3. 歌曲库

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 库为空 | 「音乐库还是空的」 | 「扫描音乐」引导 |
| 搜索无结果 | 「未找到与"xxx"相关的内容」 | 清空 / 修改关键词 |
| 筛选无结果 | 「没有符合筛选条件的歌曲」 | 「清除筛选」 |
| 不可用歌曲 | 置灰 / 标记 | 点击只提示「无可用文件」，不可播放、不入队 |

---

# 4. 标签

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 分类下无标签 | 「该分类还没有标签」 | 「新建标签」（该分类页可建） |
| 标签下无歌曲 | 标签照常展示、数量为 0；进入后「该标签下还没有歌曲」 | — |
| 歌曲无任何标签 | 列表页不显示标签区；播放页显示「暂无标签」 | — |

---

# 5. 歌词

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 未关联 | 「未关联歌词」 | 一期不提供手动选择入口（见 `03-歌词.md` §5.3） |
| 已关联但文件失效 | 「歌词文件已失效」 | 「移除关联」 |

---

# 6. 文件失效

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 播放时文件不存在 | 「文件不存在或已被移动」 | 清理该记录；实体仍有其它文件 → 自动用次大文件继续播放；实体再无文件 → 提示「该歌曲已无可用文件，是否删除？」（删除 / 保留并标记不可用） |
| 列表中已不可用 | 置灰 / 标记 | 见 §3 |

---

# 7. 系统权限

| 场景 | 展示 | 操作 |
| --- | --- | --- |
| 无读取媒体权限 | 说明用途（扫描本地音乐） | 「去授权」；拒绝后不再反复弹窗，保留入口可再触发 |
