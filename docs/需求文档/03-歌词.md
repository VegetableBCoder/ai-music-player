# 歌词系统需求文档 · V1.0

> 版本：V1.0
> 全局概念（歌曲实体、代表文件、扫描分析流水线、删除模型）见 `00-总览.md`。

---

# 1. 模块概述

## 1.1 模块目标

为本地音乐提供歌词关联和同步展示能力。歌词作为歌曲实体的附属信息存在，与歌曲绑定，而不是与具体音乐文件绑定。

## 1.2 设计原则

- 歌词属于歌曲实体
- 支持本地歌词文件
- 优先保证离线使用体验
- 支持多语言歌词展示
- 暂不依赖在线歌词服务

---

# 2. 歌词关联

## 2.1 功能描述

支持将歌词文件关联到歌曲实体。

```
歌曲实体 → 歌词文件
```

## 2.2 支持格式

一期支持：

- LRC 歌词文件

## 2.3 歌词来源

一期仅支持用户已有的 LRC 文件。

不支持：

- 在线歌词搜索
- 自动下载歌词

# 3. 歌词匹配

## 3.1 候选来源

- 音乐**同源目录**（音频文件所在目录）
- 设置里配置的**外部歌词目录**

扫描时一并索引这两处的 `.lrc` 文件。

## 3.2 匹配优先级

从高到低：

| 级别 | 规则 |
| --- | --- |
| 1 | 同源目录 + 同名（`晴天.mp3` 旁的 `晴天.lrc`） |
| 2 | 外部歌词目录 + 同名 |
| 3 | 读取 `.lrc` 的 `[ti:]` `[ar:]` `[length:]`，与实体歌名 / 歌手 / 时长匹配 |

## 3.3 匹配依据与容差

- 匹配依据：歌曲名称、歌手名称、歌曲时长（**以代表文件时长为准**）。
- 时长容差：当 `.lrc` 带 `[length:]` 时，与代表文件时长比较，**容差 ±5 秒**；超出则不匹配。
- `.lrc` 无 `[length:]` 时，只能靠歌名 + 歌手精确匹配，二者必须一致。

## 3.4 版本词处理

- 匹配时**保留版本语义词**（Live / Remix / 伴奏 / 现场 / 翻唱 等）：`晴天 (Live)` 的实体**不会**匹配到 `晴天.lrc`。
- 例外：级别 1（同源目录同名）以文件名精确相等为准，不做版本推断。
- 名称 / 歌手的比较沿用实体身份键的规范化规则（大小写、全半角、别名归一）。

## 3.5 冲突处理

- 一个 `.lrc` **只关联一个实体**（1:1）。
- 同一 `.lrc` 命中多个实体、或一个实体命中多个 `.lrc` → **不关联**，记为「未找到」（宁缺毋滥）。

## 3.6 匹配时机

- 在扫描时执行（轻量，不走 LLM）；对尚无歌词的实体尝试匹配。
- 不主动监听歌词文件变化；用户新增 `.lrc` 需**重新扫描**才会匹配。

## 3.7 编码

- 支持 UTF-8 与 GBK（含 BOM 处理）。

# 4. 歌词展示

## 4.1 同步显示

根据当前播放进度显示对应歌词，支持：

- 当前歌词高亮
- 自动滚动
- 跟随播放进度变化

## 4.2 多语言歌词

支持 LRC 中同一时间点存在多条歌词。

示例：

```
[00:12.00]故事的小黄花
[00:12.00]The little yellow flower of the story
```

展示：

```
故事的小黄花
The little yellow flower of the story
```

多语言显示方式由 LRC 文件内容控制。

# 5. 歌词管理

## 5.1 查看歌词状态

歌曲显示歌词状态：

```
晴天
歌词：✓ 已关联

七里香
歌词：× 未找到
```

## 5.2 删除歌词

支持删除歌曲关联的歌词。删除后：

- 歌曲仍然存在
- 播放不受影响
- 歌词状态变为暂无歌词

## 5.3 一期不做手动关联

- 一期**不提供**手动选择 / 更换歌词文件的入口；匹配不到即显示「未关联歌词」。

## 5.4 与实体删除的关系

删除歌曲实体时，歌词关联随实体一并删除，但磁盘上的 `.lrc` 文件保留（见 `00-总览.md` §5）。

---

# 6. 歌词文件变化

当前版本不主动处理歌词文件变化。例如 `晴天.lrc` 被用户修改，不自动重新分析。

---

# 7. 当前版本范围总结

## 已包含

- LRC 歌词支持
- 歌词关联歌曲实体
- 自动歌词匹配（同源目录 / 外部歌词目录 / 标签匹配 + 时长 ±5s）
- 歌词同步显示
- 双语歌词显示
- 歌词删除

## 暂不包含（后续规划）

- 手动选择 / 更换歌词文件
- 在线歌词搜索、自动下载歌词
- 悬浮歌词
- 歌词编辑、歌词时间轴修正
- AI 歌词翻译、歌词解析、情绪分析
