# 播放器需求文档 · V1.0

> 版本：V1.0
> 全局概念（歌曲实体、代表文件、播放会话、删除模型）见 `00-总览.md`。

---

# 1. 模块概述

## 1.1 模块目标

提供完整的本地音乐播放能力。用户可以从音乐库中的任意入口选择歌曲进行播放，并支持队列管理、播放模式控制以及播放状态记录。

## 1.2 设计原则

- 播放对象为歌曲实体
- 支持来自不同入口的歌曲播放
- 播放队列独立于歌曲来源
- 播放行为需要记录，用于后续分析和推荐
- 保持简单稳定的播放体验
- 底部常驻播放条始终可见，不被内容遮挡

# 2. 基础播放

## 2.1 播放控制

支持：

- 播放
- 暂停
- 上一首
- 下一首
- 进度调整

不支持：

- 停止
- 快进
- 快退

## 2.2 播放进度

展示当前播放时间、正在播放文件的总时长、当前播放进度，支持拖动进度条调整播放位置。

示例：

```
晴天

02:35 / 04:29

[========------]
```

# 3. 播放队列

## 3.1 队列单元与去重

- 队列单元为**歌曲实体**。
- **允许重复，不做去重**；不限制长度。

## 3.2 队列来源

歌曲可以通过以下入口加入播放队列：

- 歌曲列表
- 歌手分类
- 专辑分类
- 标签分类
- 搜索结果

## 3.3 点击歌曲播放 / 播放全部

- 点击某首歌曲 → **用当前列表新建队列**（该列表全部歌曲按当前顺序），并**从被点击的歌曲开始播放**。
- **播放全部** = 同一操作，从列表第一首开始。
- 原「清空队列只播放一首」的行为废弃。
- 不可用歌曲不入队。

## 3.4 添加到队列

- 保留当前播放状态，将歌曲追加到队列末尾。
- 允许重复。

## 3.5 下一首播放

- 将歌曲插入为**强制下一首**，允许同一首插入多次。
- 多次插入按 **LIFO**（后插入的先播）。
- **随机模式下也必须真的插队播放**，不被随机吞掉。

示例：

```
当前：A  B  C
选择：D 下一首播放，再选择 E 下一首播放
结果：A  E  D  B  C
```

# 4. 播放模式

支持三种播放模式。

## 4.1 列表循环

```
A → B → C → A → B → C
```

## 4.2 单曲循环

当前歌曲重复播放。每完整一轮视为一次会话，结算一次完整播放（见 §6）。

## 4.3 随机播放

- **每次「下一首」即时重摇**，不预生成乱序列表，也不做"短期内不重复"。
- 「上一首」按**真实播放历史**回退。
- **优先播放插队/指定的歌曲，播完再进入随机**：
  - 「下一首播放」的强制项全部播完（LIFO）后进入随机；
  - 「点击歌曲新建队列」时，被点击的歌曲先播，之后进入随机。

# 5. 播放状态保存

## 5.1 保存内容

保存：

- 当前歌曲
- 当前播放位置
- 当前播放队列（含强制下一首项）
- 当前播放模式（含随机模式的播放历史、会话最大进度）

## 5.2 恢复播放

重新打开应用时恢复：

- 上次播放歌曲
- 播放位置
- 队列状态

示例：

```
退出：晴天 03:21
重新打开：继续播放 03:21
```

# 6. 播放记录与事件

## 6.1 功能目标

记录用户播放行为，用于用户兴趣分析、后续推荐系统、智能歌单生成。

## 6.2 播放会话

一次连续播放某首歌的过程即一个会话。

- **开始**：该歌曲成为当前播放曲目并开始播放。
- **结束**：当前播放曲目发生变化（切歌、自然播完进入下一首、退出应用、进程被杀）。

## 6.3 结算指标

- 占比 = **会话内到达的最大播放进度位置 / 代表文件时长**，封顶 100%。
- 会话开始：**播放次数 +1**，并更新"最近播放"。
- 会话结算：

| 占比 | 结果 |
| --- | --- |
| ≥ 85% | 完整播放次数 ++ |
| ≤ 15% | 跳过播放次数 ++ |
| 15% < 占比 < 85% | 播放中断次数 ++ |

## 6.4 进程终止与恢复

- 进程被杀时**不单独结算**；会话状态（当前歌、播放位置、会话最大进度）随 §5 持久化。
- 恢复后视为**同一会话的延续**：播放次数不重复计，继续累计最大进度，直到真正切歌 / 退出时结算一次。

## 6.5 播放历史

支持查看：

- 最近播放列表（持久化）
- 播放歌曲列表，每首歌播放次数

## 6.6 持久化字段（每歌曲实体）

- 播放次数、完整播放次数、跳过播放次数、播放中断次数、最后播放时间
- 会话进行中额外持久化：当前歌曲、播放位置、会话最大进度

# 8. 播放控制入口与系统行为

## 8.1 控制入口

支持：

- APP 内播放控制（底部常驻播放条 + 播放页）
- 系统通知栏控制
- 锁屏控制
- 蓝牙设备控制

## 8.2 音频焦点（允许被其他应用打断）

- 短暂丢失焦点（来电、其他应用短暂提示音）→ **暂停，恢复后自动继续**。
- 永久丢失焦点（其他播放器开始播放）→ **暂停，不自动继续**，由用户决定。
- 不做"压低音量继续"。

## 8.3 耳机

- 耳机拔出 → **自动暂停**，不自动恢复。

## 8.4 后台播放

- 支持后台播放；使用**前台服务 + 常驻通知**保持运行，防止系统回收。

## 8.5 通知栏

- 展示当前歌曲 + 播放 / 暂停 / 上一首 / 下一首控制，状态实时同步。

## 8.6 锁屏

- 采用 **Android 系统原生媒体控制**（与通知栏共用同一套媒体会话）。
- **不做** QQ 音乐式的自定义锁屏播放海报。

## 已包含

- 基础播放控制与进度调整
- 播放队列（点击播放 / 播放全部 / 添加 / 下一首播放）
