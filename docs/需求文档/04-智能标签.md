# 智能标签系统需求文档 · V1.0

> 版本：V1.0
> 全局概念（歌曲实体、代表文件、扫描分析流水线、删除模型）见 `00-总览.md`。
> 本模块只负责**标签体系与标签来源（生成）**；标签的浏览、筛选、搜索、删除操作以 `01-歌曲库管理.md` 为准。

---

# 1. 模块概述

## 1.1 模块目标

为歌曲建立多维度标签体系，帮助用户更方便地浏览、筛选和发现本地音乐。

智能标签作为歌曲实体的附属信息存在。标签数据为后续智能推荐和用户兴趣分析提供基础。

## 1.2 设计原则

- 标签属于歌曲实体，而非音乐文件
- 标签用于辅助音乐分类和检索
- AI 生成标签，用户拥有最终修改权限
- 标签体系保持稳定，标签内容允许扩展
- 标签碎片化由用户把控，产品负责内置标签的质量

# 2. 标签体系

## 2.1 标签分类

分类包括：音乐类型、情绪、场景、主题。

- 分类和标签都可以由用户自建。
- **标签名称全局唯一**，一个标签只属于一个分类。
- **AI 只能新增标签，不能新增分类**；AI 生成的标签归入已有分类。

## 2.2 音乐类型

描述歌曲所属音乐类别。示例：

- 流行、摇滚、电子、古典、爵士、ACG、纯音乐

## 2.3 情绪标签

描述歌曲带来的情感倾向。示例：

- 治愈、悲伤、热血、欢快、宁静、怀旧

## 2.4 场景标签

描述歌曲适合使用的场景。示例：

- 工作、学习、驾驶、睡前、运动、旅行

## 2.5 主题标签

描述歌曲内容或文化属性。示例：

- 动漫、游戏、电影、少女乐队、青春、爱情

> 以上标签均为示例，实际标签由 LLM 分析产生，并可由用户增删。

## 2.6 主要分类

- 用户在分类页把某个分类设为「主要」（类似收藏），**预置「音乐类型 + 情绪」、可修改**。
- 歌曲列表展示主要分类下的标签。

# 3. 标签来源与生成

## 3.1 生成依据

在一次 LLM 分析中，输入 **文件名 + 歌曲元数据**，输出 **归一化数据 + 标签信息**（见 `00-总览.md` §4.2）。

标签关联对象为**歌曲实体**，不直接绑定音乐文件。

## 3.2 生成范围

生成：音乐类型标签、情绪标签、场景标签、主题标签。

## 3.3 生成规则

- 允许 AI 在分析歌曲时**添加新的标签**并为歌曲打上标签；AI 不新增分类。
- **复用机制**：把**当前有效**的分类清单 + 标签清单（实时读取，不使用固定快照）拼进 prompt，由 AI 复用已有标签。
- 允许 LLM 在没有相关知识时不输出标签信息（可以为 0 个标签）。
- 每首歌曲各类标签数量为 0~n，由 prompt 控制，避免产生大量重复或相近标签。

## 3.4 已知行为

- 由于 prompt 读取的是当前有效标签且不设黑名单，**用户删除的标签若被 AI 再次生成，会重新出现**。

## 3.5 后续规划

后续考虑提供具备联网搜索能力的 Agent Server：由 Server 端检索歌曲信息再提交给 LLM 分析，主要处理歌曲文件名不规范的问题（如歌曲名中混入歌手或其他信息）。该能力为规划项，当前不实现。

# 4. 标签管理

## 4.1 用户修改权限

用户可以修改歌曲标签，包括：

- 增加标签
- 删除标签

用户修改后的标签属于用户个人音乐库数据。

## 4.2 标签的创建与编辑

- **新建分类**：在「分类 & 标签」页添加。
- **新建标签**：在某分类下的标签列表页新建；名称全局唯一，重名时引导复用已有标签。
- 标签**只支持增删，不支持改名 / 改分类**。

## 4.3 重新分析的边界

- 已经关联到歌曲实体的文件，不支持重新分析标签。
- 未关联实体的文件可以分析。
- 需要对已有歌曲调整标签时，只能由用户手动增加或删除标签。

# 5. 标签删除

## 5.1 从标签入口删除歌曲标签

```
标签 → 选择标签 → 歌曲列表 → 删除歌曲对应标签（支持单条 / 批量操作）
```

示例：

```
治愈
歌曲：晴天
操作：移除标签
结果：晴天不再属于 治愈
```

## 5.2 从歌曲页面修改标签

```
歌曲 → 查看标签 → 增加或删除标签
```

示例：

```
晴天
标签：华语 流行 青春 治愈
操作：删除 治愈 / 增加 怀旧
```

## 5.3 删除保护

- 标签下存在歌曲时，不允许删除该标签。
- 分类下存在标签时，不允许删除该分类。
- 歌曲数量为 0 的标签仍然展示，需要用户手动删除。
- 内置分类 / 标签仅为简化使用，不设保护，允许删除。

# 6. 标签展示

## 6.1 歌曲列表展示

歌曲列表页展示**主要分类**下的标签，用于快速识别并避免占用过多空间。

```
晴天
周杰伦
[流行] [治愈]
```

## 6.2 播放页面展示

播放页面展示**完整标签信息（不折叠）**。

```
晴天  周杰伦
华语 流行 青春 怀旧 睡前 独处 校园 爱情
```

# 7. 标签搜索与筛选

- 标签搜索以 `01-歌曲库管理.md` 为准。
- 仅可在「分类 & 标签列表」页搜索标签。
- 标签筛选：按标签筛选出对应歌曲列表。

## 7.1 标签浏览

用户可以：

- 查看标签列表
- 查看标签包含歌曲数量
- 进入标签歌曲列表

# 8. 当前版本范围总结

## 已包含

- 四类标签分类与标签的生成
- AI 生成标签（可新增标签，无知识时可不输出）
- 用户增删标签、自建分类与标签
- 从标签入口 / 歌曲页面删除标签（单条、批量）
- 分类、标签的删除保护
- 主要分类设置

## 暂不包含（后续规划）

- Agent Server 联网检索歌曲信息
- 向量检索 + LLM 实体合并
- 标签维度的统计能力
- 对已关联歌曲的标签重新分析
- 标签改名 / 改分类
